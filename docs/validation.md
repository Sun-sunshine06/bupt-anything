# 验证范围

版本：0.1.0 公开候选版。当前支持 23 个工具。离线测试数量以当前 CI 或本机测试输出为准，不能将历史测试数量当作兼容性保证。

## 已覆盖

- 合成测试覆盖参数校验、认证与会话失效、账号切换、分页、未知响应、文件域名限制及正文解析。
- stdio MCP 测试覆盖工具发现、调用和错误返回；已移除的工具不能被调用。
- Windows + Python 3.12 的真实账号取样覆盖两套认证、课表、空教室、成绩、教学云课程与待办、作业详情和提交记录、互评列表、资源预览与 PDF 下载提取、历史考勤、当前活动空响应、自习候选及公开信息。
- 未提交作业仅在 `assignmentId=-1`、状态 99、正文和附件为空且作业详情交叉核对一致时返回 `not_submitted`；真实 ID 错配仍报错。
- 互评列表空对象仅在同一作业详情确认 `isOpenEvaluation=0` 后归一化，开启或未知状态仍明确报错。

## 未充分覆盖

- 多用户、长期运行、macOS/Linux 的完整安装和凭据库体验。
- 非空真实考试、测验、问卷，以及上课时的非空当前签到活动。
- 本轮可用样本的互评详情被学校标记为不可进入，未通过其他路径绕过；该链路有合成测试与以往读取验证，但仍需可访问的新样本。
- 扫描 PDF OCR、外部文件存储域名、私人日历、完整通知和提醒调度。

成功取样不能证明全部课程或所有业务状态可用。诊断方法见 [诊断说明](diagnostics.md)。本项目不进行学校端提交测试。
