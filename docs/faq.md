# bupt-anything 常见问题：北邮 MCP、课表与教学云查询

[项目首页](../README.md) · [工具参考](tools.md) · [MCP 接入](mcp.md)

## bupt-anything 是什么？与 BUPT Agent 有什么关系？

bupt-anything 是北京邮电大学（北邮，BUPT）的非官方开源校园工具箱，提供本地 MCP Server 和命令行查询入口。BUPT Agent 是同一项目的工具名称，Python 包及 CLI 命令为 `bupt-agent`，MCP 服务启动命令为 `bupt-agent-mcp`。

项目仓库为 [Sun-sunshine06/bupt-anything](https://github.com/Sun-sunshine06/bupt-anything)。项目采用 [GPL-3.0-only](../LICENSE)，与学校无隶属或背书关系。

## 能查询北邮课表、成绩和空教室吗？

可以。移动教务工具支持课表、学期、成绩、考试，以及西土城和沙河校区当天的空教室。自习规划会组合当天课表、考试和空教室，寻找连续可用节次。它不读取个人日历，空教室记录也不保证现场开门或无人使用。命令示例见 [工具参考](tools.md)。

## 教学云（UCloud）支持哪些功能？

支持查询课程、待办、作业要求、本人提交记录、教师评分与评语、本人被分配的互评，以及课程资源。可以下载已核验学校域名的文件，并提取本工具下载的 PDF、DOCX、PPTX、TXT 正文；不支持扫描文档 OCR。功能范围和真实样本覆盖程度不同，详见 [验证说明](validation.md)。

## 可以自动签到、提交作业或完成互评吗？

不可以。学校业务操作只读：考勤功能只查询本人历史记录和当前签到活动，不提供二维码解析或生成、签到提交。作业与互评工具只读取内容和状态，不提交作业或评分。详见 [考勤说明](attendance.md)。

## 必须使用 AI 才能运行吗？支持哪些客户端？

不必须。可以直接使用 `bupt-agent` 命令查询并获取 JSON。使用 AI 助手时，需要客户端支持本地 stdio MCP 服务；本项目不提供聊天界面或模型。不同客户端的配置入口可能不同，项目不保证每一种客户端版本均已验证。参见 [MCP 接入说明](mcp.md)。

## 需要什么账号？密码和查询结果会发送到哪里？

移动教务使用对应教务账号密码，教学云使用统一认证账号密码。凭据保存在本机系统凭据库，登录时交给对应认证服务；不要把密码写入聊天消息或配置文件。CLI 显示查询数据，MCP 将数据交给调用它的客户端，是否进一步发送给模型服务取决于客户端的数据处理方式。详见 [安全与隐私](../SECURITY.md)。

学校查询需要本人有权使用的账号；校园公开信息查询无需学校账号。遇到验证码或 MFA 时，当前版本无法自动完成交互认证。

## Windows、macOS 和 Linux 都能使用吗？

项目要求 Python 3.12+，使用 uv 管理依赖。Windows + Git Bash 是已验证环境；macOS Keychain 和 Linux Secret Service 凭据后端已实现，但完整安装和使用体验尚未充分验证。安装步骤见 [快速开始](../README.md#快速开始)。

## 怎样判断结果是否完整、功能是否经过验证？

工具结果包含数据来源、获取时间和完整性标记，分页列表需要继续读取后续页；接口失败会返回错误，不应理解为“没有作业”或“没有课程”。支持范围见 [工具参考](tools.md)，已覆盖与未充分覆盖的真实场景见 [验证说明](validation.md)，连接排查见 [诊断指南](diagnostics.md)。
