# 诊断与真实账号联调

## 离线检查

```bash
bash scripts/check.sh
uv build
```

离线测试不访问学校接口。错误码和合成复现通常足以报告问题。

## 需要真实账号的检查

以下脚本只读取数据。它们使用本机已有凭据，分别检查不同链路，不能放入公开 CI 或使用他人的账号：

| 命令（前缀均为 `uv run --frozen python`） | 范围 | 本地副作用 |
|---|---|---|
| `scripts/live_check.py` | 教务、教学云基础取样 | 写入聚合报告 |
| `scripts/live_mcp.py` | 独立 stdio MCP 进程与查询 | 写入聚合报告 |
| `scripts/live_attendance_readonly.py` | 当前活动查询 | 写入聚合报告 |
| `scripts/live_feedback.py` | 作业提交状态、互评列表、公开信息 | 写入聚合报告 |
| `scripts/live_resources.py` | 资料预览、下载与正文提取 | 下载一个样例到应用数据目录 |

脚本仅输出预定义状态、错误码、数量和完整性，不输出学号、课程或作业 ID、分数、正文、评语、下载链接或凭据；意外异常不会打印原始堆栈。报告位于 Git 忽略的 `artifacts/`。报告的时间与数量仍属于使用信息，分享前请复核。

取样为空、互评不可进入或遍历达到上限时，不能把一次成功响应视为所有业务场景均已验证。工具本身的 CLI 查询是用户读取数据的入口，会输出请求的内容；它不属于脱敏诊断命令。

旧的原始数据探测与全文输出脚本不随发布版本提供。协议研究请使用合成样例和已核验的只读适配器，不提交真实 HAR、前端缓存或个人资料。
